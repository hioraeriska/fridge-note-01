A make.fun entry for [Notes From a Passive-Aggressive Fridge](https://make.fun/c/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7): a program that writes one funny passive-aggressive note, 200 characters or fewer, to `/output/entry.txt`.

The note:

> The milk expired Tuesday. I told you Tuesday. It is now Friday, and you are still smelling it like it owes you an apology.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
